# Photo-tracker

## Todoワークスペース

Todoタブに「今日の行動・Inbox・一覧・プロジェクト・計画・週次レビュー」を統合しました。
「取り組む日」は締切とは別に指定できます。プロジェクトの工程と既存Main Taskのサブタスクは同じデータを参照します。
「従来リスト・ガント」で元の表示に切り替えられます。

- 既存の `ptr_*` / `photo_tracker_v1`、メールログイン、同期キー、Classroom/GASを維持します。
- 追加の整理情報は `ptr_todo_workspace` に保存し、既存の設定同期と完全バックアップに含めます。
- 保存状態と同期待ちはTodo上部に表示します。オフラインや同期失敗時は端末に残し、オンライン復帰時に再送します。「同期を再試行」でも送れます。
- 新画面で管理したタスクの完了状態は履歴として保持します。明示的な削除・非表示は従来通り利用できます。
- 初回起動時、Todo関連データを `ptr_todo_workspace_baseline_v1` に控えとして保存します。バックアップから統合前のTodoを書き出せます。
- 旧バックアップには追加情報がなくても読み込めます。試用サイトのJSONはTodo内の「バックアップ」から確認付きで統合できます。写真とアカウントは変更しません。
- 試用サイトの独立した保存領域は自動で元サイトへ上書きしません。

検証: `node --check app.js`、`node --test workspace/*.test.mjs`、`git diff --check`。

## Dia Morning Briefで今日のタスクを読む

DiaなどのAIブラウザ向けに、今日のタスクを文章中心でまとめる専用ページがあります。

- 公開URL: `https://kmc2512-crypto.github.io/Photo-tracker/?tab=brief`
- ローカル確認: `http://127.0.0.1:8767/index.html?tab=brief`

このページには「最初に確認すること」「期限切れ」「今日締め切り」「次の作業ステップ」「今後7日間」が表示されます。Diaで公開URLを開き、固定タブや日常的に見るページとして使うと、Morning Briefやページチャットがタスク内容を参照しやすくなります。

タスク内容はブラウザ内の保存データと同期データから描画されます。そのため、Diaで同じPhoto-trackerの同期キーまたはメールアカウントを設定し、専用ページを一度開いて最新のタスクが見えることを確認してください。

## iPhoneで無料運用する現実ルート

無料でPCとiPhoneの両方から使う場合は、App Store配布ではなくPWAとして使います。

1. GitHub Pagesで `https://kmc2512-crypto.github.io/Photo-tracker/` を開く
2. iPhoneの共有ボタンから「ホーム画面に追加」
3. ホーム画面のPhoto Trackerから開く
4. 設定タブで通知を許可
5. 設定タブでPCとiPhoneに同じ同期キーを入れる

## iPhoneのTodo確認

PWA単体ではiOSの本物のホーム画面ウィジェットは作れません。ホーム画面ウィジェットにするには、将来的にiOSネイティブアプリとWidgetKit拡張が必要です。

今すぐ使う現実ルートとして、iPhone向けのコンパクトTodo画面を用意しています。

- `https://kmc2512-crypto.github.io/Photo-tracker/?tab=widget`
- 一覧表示とミニガント表示を切り替え可能
- ホーム画面に追加したPWAやショートカットから開く

## 同期キー方式

Google Cloud Consoleを使えない場合は、同期キー方式でPCとiPhoneのデータをそろえます。

1. メイン端末で設定タブを開く
2. 自分だけが分かる同期キーを入力して「設定」
3. 現在のTodo・クリップ・設定・写真ログ文字情報が、その同期キー用に保存される
4. 別端末で同じ同期キーを入力して「復元」

同期キーは他人に見せないでください。キーを知っている端末は同じ保存先を使えます。
写真本体はSupabase Storage、Todo・クリップ・設定・写真ログ文字情報はSupabase settingsに保存します。

## メールログイン方式

Supabase AuthのEmail providerが有効な場合は、メールアドレスとパスワードでも使えます。

1. 設定タブでメールアドレスとパスワードを入力
2. 初回は「登録」、次回からは「ログイン」
3. 現在の端末データをアカウントへ保存する場合は「保存」
4. 別端末では同じメールでログインして「復元」

メールログイン中はメールアカウント用の保存先を優先します。ログアウトすると同期キー方式を引き続き使えます。
Supabase側でメール確認を必須にしている場合は、登録後に確認メールを開いてからログインしてください。
